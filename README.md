# 🤝 Friendship Memory App

Aplikasi *personal relationship management* untuk menyimpan catatan penting tentang teman, momen kebersamaan, dan menjaga hubungan pertemanan tetap bermakna[cite: 14, 15].

---

## ✨ Fitur Utama

- **Autentikasi Pengguna:** Sistem registrasi dan login akun pribadi pengguna[cite: 14, 16].
- **Profil Teman:** Simpan foto, nama, tanggal ulang tahun, makanan favorit, dan hobi[cite: 14, 15].
- **Catatan Kenangan:** Tulis deskripsi momen atau cerita awal pertemanan[cite: 14, 15].
- **Manajemen Data (CRUD):** Tambah, lihat detail, edit informasi, dan hapus profil teman[cite: 14, 17].

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript
- **Backend / Database:** Node.js, Express.js, MySQL (sesuaikan dengan implementasi repo kamu)
